## The number this cut nearly got wrong

v0.5.0, not v0.3.0. The roadmap had labelled this milestone *v0.3* because that is what the
specification's phase numbering calls Phase 3, while releases have counted every milestone since
M1 — so M3 shipped v0.3.0 under the label *v0.1* and M4 shipped v0.4.0 under *v0.2*. The
maintainer caught it when the review recommended the cut, and the labels were corrected in #142
and #143 before this PR touched anything. Had they not been, this release would have been cut as
v0.3.0 over a tag that already exists.

## What the roll actually involved

Not a copy. `[Unreleased]` held **52 entries across eighteen section blocks**, because every PR
inserts its own `### Added` or `### Fixed` at the top rather than merging into one. Rolling it
meant regrouping into Keep a Changelog's order — 18 Added, 18 Changed, 16 Fixed — preserving
entry order within each. The per-version file is 667 lines.

The corpus effect that bit v0.4.0 does not repeat: `docs/changelog` and `docs/releases` have
been out of the corpus since ADR-0072, so this cut *removes* 683 lines from the indexed root
`CHANGELOG.md` and adds one index row. The baseline was blessed one PR earlier against the
pre-cut tree, which is ADR-0112's cadence, and that is the tree G3 will report against until the
next release.

## What the release notes had to say plainly

Three things, because a release that hides them is worse than one that ships less.

**Two of the three retrieval legs built this milestone ship switched off.** Graph expansion lost
its ablation, hybrid cannot clear gate G2 on sets this small, and the symbol leg lost three times
before earning it. Written as a table with the ADR behind each verdict, not as an omission.

**A milestone exit gate is unmet.** Ten external repositories dogfooding stands at zero, carried
into M6 as 6.12 with 6.11 — publish the package — named as its blocker. The notes say so under
*Known limits* rather than in a footnote.

**The judged sets are too small for their own per-slice conditions**, which is why hybrid cannot
be promoted and will not be until 6.8 lands.

## Lesson

A release cut is the one moment where every label in the repository is read as a claim about the
artifact. Two of ours had been wrong for two milestones and nobody had looked, because nothing
reads a milestone heading until something has to be named after it. The lint checks version
lockstep between the badge, the version file and the newest release notes — it does not check
that a milestone heading names the version that milestone shipped, and that is the gap this cut
walked into.
