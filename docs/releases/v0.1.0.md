# mycelium-os v0.1.0

**Released:** 2026-08-29
**Milestone:** [1 — Project bootstrap & CI](../../ROADMAP.md#milestone-1--project-bootstrap--ci) (complete)

## Highlights

This is the project's first release: the governed scaffolding, build system, and CI gate
that every later milestone builds on. There is no product surface yet — `mycelium-os` does
not compile or serve knowledge in this release. What v0.1.0 proves is that the repository
itself is enterprise-grade: buildable, tested, linted, type-checked, and green on every
supported platform.

- **Governance & delivery pipeline.** The EADOS-generated agent contract (`AGENTS.md`),
  documentation system, consistency lint, and negotiated `ROADMAP.md` (RFC-0001) that every
  contribution — human or agent — now follows.
- **Buildable package.** `pyproject.toml` on Hatch (PEP 517/518); a minimal, importable
  `mycelium` package under `src/mycelium/` (flat src-layout, [ADR-0003](../adr/0003-adopt-flat-python-src-layout.md)).
- **Test framework.** pytest + hypothesis wired as the `dev` dependency group, with a
  passing smoke test.
- **Quality gate.** `ruff format` (Black-compatible), `ruff check`, and `mypy --strict`
  configured and clean; `uv.lock` committed.
- **CI matrix.** Build, test, lint, benchmark, and the consistency lint all green on
  Linux, Windows, and macOS across CPython 3.12 and 3.13.
- **Governance files.** `LICENSE` (Apache-2.0), `SECURITY.md`, `CONTRIBUTING.md` (DCO),
  and `CODE_OF_CONDUCT.md` (Contributor Covenant v2.1).

## Fixed

Three bugs found and fixed while standing up the pipeline itself — see
[`CHANGELOG.md`](../changelog/v0/v0.1.0.md#fixed) for details:

- BUG-0001 — a dead `matrix.toolchain` reference in the release workflow.
- BUG-0002 — CI/release steps invoking tools not on `PATH` after `uv sync`.
- BUG-0003 — the CI bootstrap guard activating toolchain jobs before the toolchain was
  declared.

## Upgrading

Nothing to upgrade — this is the first release. Install from source:

```bash
uv sync --all-extras --dev
uv run pytest -q
```
