# mycelium-os v0.5.0

**Released:** 2026-09-14
**Milestone:** [5 — Structure (spec Phase 3)](../../ROADMAP.md#milestone-5--v050--structure-spec-phase-3) (three of four exit gates met; the fourth carried by name)

## Highlights

v0.4.0 compiled the documents you were given. **v0.5.0 gives what it compiles a structure you
can ask questions of** — a symbol table, a typed graph, and citations that tell you when the
ground has moved under them.

```bash
mycelium build                         # symbols and typed edges compile with everything else
mycelium neighbors docs/api.md         # what this cites, and what cites it
mycelium search "RetryPolicy" --explain   # which leg proposed each passage, and why
mycelium show "mycelium://<id>#retries/0?lines=12-31"   # and whether it still says that
```

- **A symbol table, from each language's own idea of a definition.** Code fences are read
  through the `tags.scm` query the grammar ships — the one GitHub's code navigation runs — for
  nine languages, and every definition is qualified by its nesting, so `delay` inside
  `class RetryPolicy` is `sym:python:RetryPolicy.delay` whether the fence is Python, Rust or
  Java. Documentation defines terms through the syntax documentation actually uses: definition
  lists, and headings whose text *is* an identifier. The grammars are an optional extra, and a
  build without them says what it could not read (ADR-0073).
- **A typed edge vocabulary, traversable in both directions.** Wikilinks, cross-references and
  the symbol table produce `links_to`, `defines` and `references` edges with an `authored` or
  `extracted` status that never silently upgrades. `mycelium_neighbors` answers *what does this
  cite* and *what cites this* in one hop each (ADR-0074, ADR-0084).
- **Citations that admit when a passage has moved.** Every `mycelium://` URI is minted with the
  lines it was taken from, and both read surfaces honour them: a heading rename or a reordered
  section returns the content *with* a `stale` block naming what was cited, where it is now and
  the URI to cite instead. Proven across eleven named refactorings, which is how the defect was
  found — an anchor's ordinal is a position, so a citation to the first of two sections that
  slugify alike had been returning the second (roadmap 5.6).
- **The first contrib module.** `chats` imports a conversation archive, projects it as Markdown
  the compiler picks up like any document, and passes all six of document 08's acceptance gates
  — using only the public extension points, with the one core change the sixth gate's own text
  authorises (ADR-0077).
- **An ingested corpus is finally in the graph.** A relative link in a projected document used
  to resolve against nothing, so the ingested twin compiled 10 edges where its Markdown source
  compiled 229. It resolves now (roadmap 5.7).

## What is switched off, and why that is the point

Three candidate retrieval legs were built and ablated this milestone. **Two ship disabled.**

| leg | verdict | where |
|---|---|---|
| graph expansion | lost; ships off | ADR-0075 |
| symbol lookup | refused three times, earned at the fourth; ships **on** | ADR-0094 |
| hybrid (vector) retrieval | cannot clear gate G2's bar on sets this size | ADR-0069 |

Each is a measurement with the arithmetic written down, not a preference. Graph expansion in
particular was measured *before* any code existed: one hop from ten seeds reaches 530 of this
repository's 982 chunks, so the budget is the mechanism rather than a safety margin, and every
edge type the specification suggested weighting turned out to have nothing to act on.

## Measured

Release sets — the ones nobody develops against — scored against the agent's own `grep` loop,
which is the bar D-010 sets:

| release set | Mycelium OS | the `grep` loop |
|---|---:|---:|
| `uv`'s documentation | **0.614** | 0.532 |
| the same documents, ingested from DOCX/HTML/PDF | **0.614** | 0.575 |
| this repository, measured at the cut | **0.521** | 0.263 |

The third row is this repository scoring itself, so it moves when the repository does — and the
cut itself moved it. Rolling 683 lines of `[Unreleased]` out of the indexed `CHANGELOG.md` gave
the incumbent 0.247 → **0.263** and us 0.523 → 0.521, narrowing the reported lead from +0.276 to
+0.259. A term-counting baseline gains more from a smaller corpus than a field-weighted index
does, which is the same asymmetry the other direction: over this milestone sixteen documents
arriving diluted grep by 13 % while leaving us within half a percent. That asymmetry *is* the
claim the project was built to test, and it is why the baseline behind that row is now re-blessed
once per release rather than whenever somebody notices (ADR-0112, ADR-0072).

## Known limits

- **Ten external repositories dogfooding: zero.** Milestone 5's fourth exit gate is unmet and
  carried into Milestone 6 by name rather than waived, with the blocker underneath it named for
  the first time — the package is not published to any index, so nothing can dogfood it yet
  (roadmap 6.11, 6.12; ADR-0113).
- **The judged sets are too small for their own per-slice conditions.** Four to seven cases a
  slice means a single losing case trips the slice on its own; the arithmetic says ~35 are needed
  and the specification asks for 1 000 at 1.0 (roadmap 6.8).
- **Hybrid retrieval stays off**, and cannot be promoted until those sets grow — the bar is not
  moved to fit a candidate.
- The five stable contracts are not frozen yet; that is Milestone 6.

## Upgrading

`PARSE_STAGE_VERSION` and the store schema moved this milestone, so **the first build after
upgrading recompiles**. Nothing is required of you: the store is derived data and rebuilds
itself. Symbol extraction from code fences needs the optional `symbols` extra; without it a
build still succeeds and its snapshot says which fence languages it could not read.

**How to install, honestly:** from the wheel or sdist attached to this release, or from a
clone with `uv sync --all-extras --dev`. `mycelium-os` is not on a package index yet — the
release workflow builds and attaches the artifacts and stops there — so the `pip install
mycelium-os[…]` lines elsewhere in the documentation describe an intended future rather than
today. Publishing is roadmap 6.11.
